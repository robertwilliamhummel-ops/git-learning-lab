## 1. Brand Identity Overview

### Core Brand Elements

**Company Name:** TechFlow Solutions  
**Tagline:** "Toronto's Tech Experts"  
**Industry:** Technology Services (Web Design, SEO, Computer Repair)  
**Location:** Toronto, Ontario, Canada  
**Target Market:** Local businesses and individuals needing tech solutions

### Brand Color Palette

| Color | Hex Code | Usage |
|-------|----------|-------|
| **Primary Purple** | `#667eea` | Gradient start, primary accents |
| **Secondary Purple** | `#764ba2` | Gradient end, secondary accents |
| **Accent Blue** | `#4A90E2` | Highlights, call-to-action elements |
| **Dark Background Start** | `#0a0a1a` | Background gradient start |
| **Dark Background End** | `#1a1a2e` | Background gradient end |
| **Neon Glow** | Purple at 20-30% opacity | Glow effects around elements |

### Brand Style Guidelines

- **Visual Style:** Modern, futuristic, professional, tech-forward
- **Key Visual Elements:** 
  - Microchip/circuit board patterns
  - Glassmorphism effects (frosted glass)
  - Holographic/3D elements
  - Geometric shapes (hexagons, triangles)
  - Light particles/bokeh effects
  - Flowing data streams
  - Purple gradient overlays

### Design Principles

1. **Consistency:** Purple gradient (#667eea to #764ba2) across ALL assets
2. **Professionalism:** Clean, modern, enterprise-ready aesthetics
3. **Local Identity:** Toronto landmarks (CN Tower) when appropriate
4. **Service Focus:** Clear communication of three core services
5. **Scalability:** Designs must work at all sizes (16x16px to 1920x1080px)

## 2. Logo Design System

### 2.1 Primary Logo (Universal Version) ⭐

**Specifications:**
- **Recommended Size:** 1200x1200px square (AI tools will output whatever size they generate)
- **Format:** PNG with transparent background
- **File Naming:** `logo-primary.png`
- **Usage:** Everywhere - website, Google Business, business cards, social media, documents

**✅ SIMPLIFIED: ONE LOGO WORKS EVERYWHERE!**

**Design Prompt:**
```
Create a modern tech company logo for "TechFlow Solutions" on transparent background. Design a sleek microchip icon with circuit pathways forming the letters "TF" in the center. The icon uses purple-blue gradient (#667eea to #764ba2) with subtle neon glow effect. Add flowing data streams or network connections around the microchip. Include "TechFlow Solutions" text in PURPLE GRADIENT (#667eea to #764ba2) - same gradient as the icon - in clean modern sans-serif font next to the icon. Style: Minimalist, professional, futuristic tech aesthetic. Horizontal layout with icon on left, text on right. The microchip should have clean geometric lines with hexagonal elements. Include subtle holographic/glassmorphism effect. Make it recognizable at small sizes. High contrast, sharp edges. Mood: Innovation, reliability, cutting-edge technology. Square composition, high resolution.
```

**📝 Note on AI Tool Sizes:**
- AI tools like Gemini, Ideogram, and DALL-E output their own default sizes (typically 1024x1024px or 1536x1536px)
- You cannot specify exact pixel dimensions in most AI tools
- Whatever size the AI generates will work fine - just use it as-is
- If needed, resize later in Canva or image editor to exactly 1200x1200px

**Why Purple Gradient Text is Perfect:**
- ✅ Visible on white backgrounds (Google Business Profile)
- ✅ Visible on dark backgrounds (website, PC dark theme)
- ✅ Matches your brand colors perfectly
- ✅ Works on ALL backgrounds (gray, colored, etc.)
- ✅ No need for multiple versions!

## 4. Business Card Design

### 4.1 Business Card Specifications

- **Size:** 3.5" x 2" (standard business card)
- **Resolution:** 1050x600px at 300 DPI
- **Format:** PDF for printing, PNG for digital preview
- **Color Profile:** CMYK for printing, RGB for digital
- **Bleed:** Add 0.125" bleed on all sides for professional printing

### 4.2 Business Card Front

**File Naming:** `business-card-front.png`

**Design Prompt:**
```
Design a modern business card front (3.5" x 2", 1050x600px, 300 DPI) for TechFlow Solutions. 

Layout:
- Left third: TechFlow Solutions logo (microchip icon with circuit patterns) in purple gradient (#667eea to #764ba2)
- Center: Company name "TechFlow Solutions" in bold modern sans-serif font (white text)
- Right third: Purple gradient background (#667eea to #764ba2) with subtle circuit board pattern
- Bottom: Tagline "Web Design • SEO • Computer Repair" in smaller white text

Background: Dark navy (#0a0a1a) transitioning to purple gradient on right side
Effects: Glassmorphism effect on logo area, subtle holographic accents
Style: Professional, tech-forward, minimalist, high-end
Mood: Innovation, expertise, modern technology

Ensure text is readable and logo is prominent. Leave back for contact information.
```

### 4.3 Business Card Back

**File Naming:** `business-card-back.png`

**Design Prompt:**
```
Design business card back (3.5" x 2", 1050x600px, 300 DPI) for TechFlow Solutions.

Contact Information (with icons):
📱 Phone: (647) 572-8321
📧 Email: rob@techflowsolutions.ca
🌐 Website: techflowsolutions.ca
📍 Location: Toronto, Ontario

Layout: 
- Contact info centered or left-aligned with icon bullets
- Icons in purple gradient (#667eea to #764ba2)
- Text in white, clean sans-serif font
- Small TechFlow logo (microchip icon only) in top-right or bottom-right corner
- Optional: QR code linking to website in bottom-left corner

Background: Continuation of front design with subtle circuit patterns and purple gradient accents
Style: Clean, readable, professional, matches front design perfectly
Ensure phone number and email are most prominent for easy scanning.
```

### 4.4 Business Card Printing Checklist

- [ ] Generate front design at 300 DPI
- [ ] Generate back design at 300 DPI
- [ ] Print test on regular paper to check sizing
- [ ] Convert to CMYK color profile for printing
- [ ] Add 0.125" bleed to all sides
- [ ] Export as high-res PDF
- [ ] Order 500 cards from VistaPrint, Moo, or local printer ($50-100)

### Image Optimization Guidelines

1. **Compression:** Use TinyPNG or ImageOptim to reduce file size
2. **Format Choice:**
   - PNG: Logos, icons (need transparency)
   - JPG: Photos, hero images (no transparency needed)
   - SVG: Scalable graphics when possible
3. **Responsive Images:** Serve different sizes based on device
4. **Lazy Loading:** Implement for hero images below fold
5. **CDN:** Use image CDN for faster delivery

### Color Profile Conversion

**For Digital Use (RGB):**
- Primary Purple: #667eea
- Secondary Purple: #764ba2

**For Print Use (CMYK):**
- Primary Purple: C:60 M:50 Y:0 K:0
- Secondary Purple: C:55 M:60 Y:0 K:0

**Note:** Always get a physical proof before large print runs, as CMYK colors may vary from screen RGB.

## 10. AI Image Generation Tips

### Best AI Tools for TechFlow Branding

1. **Gemini 2.5 Flash** (Google AI Studio) - FREE
   - Best for: Technical illustrations, futuristic themes
   - Prompt Style: Detailed, technical descriptions
   - Speed: Very fast (5-10 seconds)

2. **Midjourney** (Discord) - PAID ($10/month)
   - Best for: Artistic quality, consistent style
   - Prompt Style: Artistic, stylistic keywords
   - Speed: Fast (30-60 seconds)

3. **DALL-E 3** (ChatGPT Plus) - PAID ($20/month)
   - Best for: Precise control, text integration
   - Prompt Style: Natural language descriptions
   - Speed: Medium (30-90 seconds)

4. **Leonardo.ai** - FREEMIUM
   - Best for: Consistent character/style, fine control
   - Prompt Style: Detailed with style presets
   - Speed: Fast (15-30 seconds)

5. **Ideogram.ai** - FREEMIUM
   - Best for: Text in images, logos with text
   - Prompt Style: Text-focused prompts
   - Speed: Fast (20-40 seconds)

### Pro Tips for Consistent Results

#### 1. Use the Same Tool for Related Images
Generate all homepage hero slides with the same AI tool to maintain visual consistency.

#### 2. Save Your Prompts
Keep a document with successful prompts so you can iterate and improve.

#### 3. Generate Multiple Versions
Create 3-4 variations of each image and pick the best one.

#### 4. Iterate on Details
If an image is 80% perfect, describe what needs changing in a follow-up prompt.

#### 5. Reference Previous Images
When generating a series, reference earlier images: "Similar style to previous image but with..."

#### 6. Specify Technical Details
Always include: dimensions, color codes, style keywords, mood, lighting.

### Common Prompt Issues & Solutions

**Problem:** Text in logo is blurry or misspelled  
**Solution:** Use Ideogram.ai specifically for text, or use "clean, readable sans-serif font"

**Problem:** Colors don't match brand (#667eea to #764ba2)  
**Solution:** Explicitly state exact hex codes and "purple-blue gradient"

**Problem:** Image too busy or cluttered  
**Solution:** Add "minimalist", "clean", "professional" to prompt

**Problem:** Not futuristic enough  
**Solution:** Add "holographic", "neon", "cyberpunk-inspired", "glassmorphism"

**Problem:** Inconsistent style across images  
**Solution:** Use same AI tool and include "consistent with previous images" in prompt

### Prompt Structure Template

Use this structure for best results:

```
[Type] ([Dimensions]) showing [Main Subject] with [Key Elements]. 
Feature [Important Detail] in [Brand Colors]. 
Include [Additional Elements]. 
Add [Effects/Patterns]. 
Style: [Style Keywords]. 
Background: [Background Description]. 
Mood: [Emotional Tone].
```

**Example:**
```
Hero image (1024x1024px) showing holographic workspace with floating code. 
Feature central microchip in purple gradient (#667eea to #764ba2). 
Include circuit patterns and Toronto CN Tower. 
Add glassmorphism effects and particle lighting. 
Style: Modern, futuristic, professional. 
Background: Dark navy with neon accents. 
Mood: Innovation, cutting-edge technology.
```

### Quality Checklist Before Using Image

Before uploading any generated image, verify:

- [ ] Colors match brand palette (purple gradient #667eea to #764ba2)
- [ ] Resolution is correct (1024x1024px or 1200x1200px)
- [ ] Image is sharp and high quality (not pixelated)
- [ ] Composition works at different sizes
- [ ] Text (if any) is readable and spelled correctly
- [ ] Style matches other brand images
- [ ] File size is optimized (<500KB for web)
- [ ] Mood/emotion aligns with page purpose
