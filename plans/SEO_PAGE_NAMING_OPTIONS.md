## Alternative: Dropdown Menu Approach

If you want to keep navigation clean, use a dropdown:

### Main Navigation
```
Home | Website Design | IT Services | About | Contact
```

### Website Design Dropdown
```
Website Design
  ↳ Custom Website Design
  ↳ Website Redesign
  ↳ Search Optimization Add-On
```

This way:
- "Search Optimization" is available but not in main nav
- Positions SEO as add-on to web design
- Keeps navigation clean and simple
- Still creates a dedicated page for SEO keywords
