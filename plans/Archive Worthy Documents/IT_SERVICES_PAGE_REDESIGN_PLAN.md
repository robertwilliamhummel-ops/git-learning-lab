## CTA STRATEGY

### Primary CTAs:
1. **Hero Section:** "Request Consultation" + "View Services"
2. **Service Cards:** "Learn More" (scroll to details) or "Get Quote"
3. **Final CTA:** "Schedule Free Consultation"

### CTA Button Destinations:

#### Option 1: Contact Form (Recommended)
- Link all CTAs to contact.html
- Simple, direct
- Lower friction
- Easier to track

#### Option 2: Booking Page
- Link to booking.html
- Pre-fill service type
- Shows available times
- More commitment required

#### Option 3: Hybrid Approach
- Hero CTA → Contact form (low friction)
- Service cards → Booking page with service pre-selected
- Final CTA → Contact form

**Recommendation:** Start with Option 1 (contact form), measure conversion rates, then test Option 3

### Contact Form vs Booking System:

**Contact Form Advantages:**
- ✅ Lower barrier to entry
- ✅ Client can describe needs
- ✅ Flexible scheduling
- ✅ Better for custom projects
- ✅ Higher conversion rates

**Booking System Advantages:**
- ✅ Immediate scheduling
- ✅ Automated calendar
- ✅ Shows availability
- ✅ Reduces back-and-forth

**For IT Services:** Contact form is better because:
- Each project is custom
- Needs assessment call first
- Can't book "managed IT" like a haircut appointment
- Booking works better for one-time services (which we're moving away from)

## MOBILE OPTIMIZATION

### Current Issues (Computer Repair Page):
- ❌ Collapsible sections hard to use on mobile
- ❌ Calculator requires too much scrolling
- ❌ Service list overwhelms small screens
- ❌ Click hints not intuitive on touch

### New Mobile Strategy:

#### Hero Section:
```css
/* Mobile: Stack CTAs vertically */
@media (max-width: 768px) {
  .hero-cta-buttons {
    flex-direction: column;
    gap: 1rem;
  }
  .btn-hero {
    width: 100%;
  }
}
```

#### Service Cards:
```css
/* Mobile: Single column, larger touch targets */
@media (max-width: 768px) {
  .services-grid {
    grid-template-columns: 1fr;
  }
  .service-card {
    min-height: auto;
    padding: 2rem;
  }
}
```

#### Typography:
```css
/* Mobile: Responsive font sizes */
.hero-title {
  font-size: clamp(2rem, 8vw, 5rem);
}
.hero-subtitle {
  font-size: clamp(1rem, 4vw, 1.5rem);
}
```
