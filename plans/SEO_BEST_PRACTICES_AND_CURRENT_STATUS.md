## 🎯 PART 1: HOW TO BUILD A NEW WEBSITE (THE RIGHT Way)

### Step 1: SEO Research BEFORE Writing Code (4-6 hours)

#### A. Keyword Research
```
1. List your services (what you actually do)
2. Google each service + your city name
3. Use Google autocomplete to see what people search
4. Check search volume (Google Keyword Planner - free)
5. Pick 3-5 PRIMARY keywords (high volume, medium competition)
6. Pick 10-15 SECONDARY keywords (supporting topics)
```

**Example for TechFlow Solutions:**
```
PRIMARY KEYWORDS:
✅ "website design Toronto" (1,200/month)
✅ "computer repair Toronto" (1,200/month)
✅ "SEO services Toronto" (720/month)

SECONDARY KEYWORDS:
✅ "custom website design GTA" (320/month)
✅ "laptop repair Toronto" (880/month)
✅ "PC repair Toronto" (590/month)
✅ "IT support Toronto" (480/month)
✅ "remote computer support" (260/month)
```

#### B. Plan URL Structure
```
RULE: Use exact keyword phrases with hyphens

✅ GOOD URLs:
- website-design.html (matches "website design")
- seo-services.html (matches "SEO services")
- computer-repair.html (matches "computer repair")

❌ BAD URLs:
- custom-websites.html (nobody searches "custom websites")
- seo-optimization.html (people search "SEO services" not "SEO optimization")
- pc-fix.html (too casual, doesn't match searches)
```

#### C. Write Meta Tags BEFORE Building
```
For EACH page, write:

1. TITLE TAG (50-60 characters)
   Format: [Service] | [Business Name] | [City]
   Example: "Website Design Toronto | TechFlow Solutions | Custom Sites"

2. META DESCRIPTION (150-160 characters)
   Include: service, benefit, location, call-to-action
   Example: "Professional website design in Toronto. Custom, mobile-responsive sites that drive business growth. Free consultation. Call (647) 572-8321"

3. META KEYWORDS (10-15 keywords)
   Include: primary keyword, variations, location keywords
   Example: "website design Toronto, custom websites GTA, web design services, Toronto web developer"
```

#### D. Plan Sitemap Structure
```
Before building, list ALL pages with priority:

Priority 1.0 (Homepage):
- index.html

Priority 0.9 (Main Services):
- website-design.html
- seo-services.html
- computer-repair.html

Priority 0.8 (Conversion Pages):
- booking.html
- contact.html

Priority 0.7 (Supporting Pages):
- about.html
- remote-support.html
```

### Step 2: Build Website WITH SEO Baked In (12-16 hours)

```
1. Create HTML files with SEO-optimized filenames
2. Add ALL meta tags to <head> FIRST
3. Write content using target keywords naturally (not stuffed)
4. Add internal links between related pages
5. Use header tags properly (H1 for main title, H2 for sections)
6. Add alt text to images with keywords
7. Create sitemap.xml as you build
8. Test on mobile (Google ranks mobile-first)
```

### Step 3: Make It Pretty (4-6 hours)

```
NOW add design:
1. Colors and branding
2. Animations and effects
3. Custom graphics
4. Polish and refinement

SEO is DONE - just making it look good!
```

### Step 4: Launch & Submit (1-2 hours)

```
1. Create Google Business Profile
2. Set up Google Search Console
3. Submit sitemap.xml
4. Verify ownership
5. Start tracking rankings
```
